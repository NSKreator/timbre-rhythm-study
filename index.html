Reading the plots. Each point represents one audio file. Song index follows the row order in results.csv. Only available measurements are shown in each view; missing values are never plotted as zero.

Methods and keyboard controls

Tab through controls and points. On a point, arrow keys move between songs, Enter or Space toggles selection, and Escape releases it. Search accepts part of an artist name or title and ignores case. Press Enter in search to select the first match; other matches stay enlarged. Clear restores point sizes. The two groups follow the researcher's division, not automatic genre classification.
